# 公開Web調査とファクトチェック

## 確認できた情報

- Code for CAT公式サイトは、「テクノロジーによりネコとヒトの素敵な関係を作ります。」を掲げ、地域猫を地域の資産として捉え、殺処分・収容数ゼロを目指す団体の活動をITで支援すると説明している。
- 公式サイトではCatBotを猫に関する質問に答えるChatBotとして説明し、CatBot β版公開中と表記している。
- 公式サイトではCatdonを猫好き向けMastodonとして紹介している。
- Code for Japanのシビックテックプロジェクトページでは、Code for CATがCode for SAKEと並ぶテーマ型・地域横断型の取り組みとして紹介されている。
- Code for JapanのSocial Hack Dayページでは、Code for CATが地域猫問題解決に寄与するLINE Chatbotを作っている代表的プロジェクトとして紹介されている。
- Catdonのaboutページでは、猫好き向けMastodonであること、公開時点のユーザー数・投稿数が確認できる。
- Medium「猫たちの夏2019」では、Code for CATが2016年以来毎年石巻ハッカソンに参加していたこと、2016年は田代島ツアー＆キャットソン、2017年は猫＋地図アプリ、2018年は御神体、2019年は地域猫カードゲームだったことが説明されている。

## 確認度に注意が必要な情報

- 2015年CIVIC TECH FORUMアンカンファレンスとCode for Japan Summit 2015での正式発足は、Medium記事に基づく。イベント公式記録での再確認が望ましい。
- Catdonの立ち上げ日、ネコ市ネコ座ライタソン、NECOLOの詳細は、公開記事に基づく。一次情報または関係者確認が望ましい。
- 2021年〜2024年は、公開Webで体系的な活動記録を確認しにくい。活動停止とは断定しない。
- 2025年Podcastの生成AI・猫エージェントの話題は、公開ページ上の情報とユーザー提供調査に基づく。音声内容の聴取確認が望ましい。
